# Sacred Verses — Daily Wisdom

One verse from the world's scriptures, every morning. A free, lightweight Android app with no ads, no tracking, and no account needed.

## Features

- **Verse of the day** — a new hand-picked verse each morning from six traditions: Hinduism, Christianity, Islam, Buddhism, Judaism, and Sikhism. Or follow one faith with the "My faith" preference.
- **Morning reminder** — a gentle notification with the day's verse at the time you choose (one-tap presets: Morning, Midday, Evening, Night, or a custom time).
- **Lockscreen wallpaper (optional)** — wake up to the verse as your lockscreen wallpaper, rendered fresh each morning. Off by default; enable it in Settings.
- **Browse all 365 verses** — a full year of unique verses, filterable by faith, with search-friendly browsing across tabs.
- **Favorites** — save the verses that move you, revisit them anytime.
- **Share** — send any verse to friends and family in one tap.
- **Sponsored book picks** — a small daily-rotating book recommendation card (affiliate links that keep the app free, dismissible anytime).
- **Support the app** — an optional in-app way to contribute via UPI.

All verses are quoted verbatim from public-domain translations (KJV Bible, Sir Edwin Arnold's Gita, Pickthall's Qur'an, Müller's Dhammapada, JPS Tanakh, Macauliffe's Sikh Religion), attributed in-app.

## Install

Grab the latest APK from the [Releases page](../../releases) and install it (allow "install unknown apps" when prompted). Requires Android 8.0+.

## Privacy

The app works fully offline. It stores your preferences (faith, reminder time, favorites) only on your device, shows no ads, uses no analytics, and creates no account. The notification permission is used solely for the daily verse reminder. Contact: sacredversesapp@gmail.com.

## Build

Pure Java, zero dependencies. Build with the manual script (aapt2 + javac + d8):

```sh
./build-manual.sh
```
